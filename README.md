# Stalwise

Horse business management app for stables, studs and trading yards. Built first for Kimco Stables & Stud, then offered to other yards as a subscription product.

## Stack

- **App:** Expo (React Native, Expo Router, TypeScript) for iPhone, Android and web
- **Backend:** Supabase (Postgres, Auth, Storage)
- **Offline sync:** PowerSync
- **Builds and testing:** Expo EAS and Apple TestFlight

## Blueprint

The product blueprint and database design live in the Stalwise Blueprint v2 doc. Phase 1 is the version Kimco tests first.
